# ml-images
ML classifier for images.  
  
Image set courtesy of Sanagapati via Kaggle: [https://www.kaggle.com/datasets/pavansanagapati/images-dataset](https://www.kaggle.com/datasets/pavansanagapati/images-dataset)  
Includes 1803 samples across 7 categories: bike, cars, cats, dogs, flowers, horses, human

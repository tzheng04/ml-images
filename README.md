# ml-images  
ML classifier for handwritten characters.  
  
Image set donwloaded via Kaggle: [https://www.kaggle.com/datasets/dhruvildave/english-handwritten-characters-dataset](https://www.kaggle.com/datasets/dhruvildave/english-handwritten-characters-dataset)  
Includes 62 different characters with 55 images of each class.  

## References  
de Campos, T. E., Babu, B. R., & Varma, M. (2009). *Character recognition in natural images*. Proceedings of the International Conference on Computer Vision Theory and Applications, Lisbon, Portugal.
